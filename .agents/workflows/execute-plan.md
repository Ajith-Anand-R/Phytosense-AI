# Plan Execution Workflow

Use this workflow to execute an implementation plan generated by `@writing-plans`.

## Steps:
1. **Activate Skill:**
   Activate `@executing-plans`.
2. **Review Tracker:**
   - Inspect `docs/plans/task.md` to identify remaining tasks.
3. **Batch Execution (1–3 Tasks):**
   - Execute in strict TDD order: failing test -> confirm fail -> minimal code -> confirm pass -> commit.
4. **Checkpoint Review:**
   - Report progress and test results after each batch.
   - Halt immediately if unexpected errors or interface breaks occur.
5. **Final Verification:**
   - Run full project test suite and verify clean git status.
